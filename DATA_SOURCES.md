This file is a generated, validated artifact. Once the dataset tooling exists (plan steps 3–5), it will be regenerated from the committed dataset manifests: one row per source with its license, declared version, files and bytes kept/dropped, and drop reasons.

Generation is deterministic: rows are sorted, timestamps are excluded, and absolute paths are not recorded. CI regenerates this file and fails if the generated output differs from the committed copy.

Until the first dataset manifest is committed, there are no dataset sources to record. During this phase, CI verifies that this file correctly states that no dataset has been built.
