# KittyLM Model Weights License

**No KittyLM model weights have been trained or released yet.**

Any KittyLM model weights released by the project will be licensed under the Apache License, Version 2.0

Every released checkpoint will be accompanied by:

- its experiment record (`experiments/<ID>/record.yaml`), which pins the git commit, dataset
  version, tokenizer version, configuration and measured results;
- the training data provenance in [DATA_SOURCES.md](DATA_SOURCES.md), including each source's
  individual license;
- known limitations ([docs/limitations.md](docs/limitations.md)).

The Apache-2.0 license on weights does not change the licenses of the underlying training
sources, which are recorded per source.
